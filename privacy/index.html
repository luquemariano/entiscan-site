Política de Privacidad de EntiScan

Última actualización: 7 de octubre de 2026

EntiScan es una extensión de navegador que analiza la página web activa para generar una auditoría SEO local, incluyendo señales técnicas y on-page, estructura de encabezados, enlaces, imágenes, datos estructurados, metadatos sociales, entidades y coherencia semántica.

Procesamiento local

EntiScan procesa la información de la página directamente en el navegador del usuario. La extensión no requiere una cuenta, no utiliza un backend propio para realizar las auditorías y no envía automáticamente el contenido analizado a servidores externos.

Datos procesados

Para realizar la auditoría, EntiScan puede procesar localmente información asociada a la página activa, incluyendo su URL, título, contenido visible, estructura HTML relevante para SEO, enlaces, imágenes, metadatos, datos estructurados y otras señales relacionadas con el análisis.

Sincronización opcional con EntiScan Web

A partir de la versión 0.2.0, podés conectar opcionalmente un espacio de EntiScan Web para guardar auditorías. La extensión sigue funcionando sin cuenta y sin conexión. No hay sincronización automática, auditorías programadas ni seguimiento en segundo plano.

La conexión se autoriza en la web; la contraseña no se guarda en la extensión. Conectar no envía auditorías. Para cada envío debés pulsar «Guardar en EntiScan Web», elegir un proyecto, revisar el resumen y confirmar.

Qué se envía al confirmar

Se envían la URL normalizada, fecha y versiones de la auditoría, metadatos SEO, hallazgos, recomendaciones, nombres y relaciones de entidades observadas, encabezados acotados, conteos de enlaces e imágenes y resúmenes de señales técnicas, sociales y de datos estructurados. Estos datos se guardan en el proyecto elegido para mostrar historial y comparación de snapshots.

Los títulos, encabezados y nombres de entidades pueden contener información identificable de la página. No envíes auditorías de páginas privadas o sensibles. Se eliminan parámetros de seguimiento y se rechazan URLs con parámetros reconocidos de credenciales o sesión; estas medidas no garantizan detectar toda información sensible en una página.

Datos excluidos del envío

La sincronización no envía HTML completo, JSON-LD completo, capturas, cookies, localStorage o sessionStorage del sitio, campos de formularios, contenido de inputs, contraseñas ni headers de sesión del sitio auditado. No se recopilan datos adicionales de la página para sincronizar. Las auditorías se calculan localmente, sin análisis remoto de IA.

Conexión, almacenamiento y revocación

La extensión conserva en chrome.storage.local un token propio de EntiScan y metadatos mínimos de conexión, incluida la autorización temporal pendiente. No conserva contraseñas ni tokens de GSC. El token permite leer los proyectos del usuario y guardar auditorías confirmadas; vence en 30 días y puede revocarse en Settings → Connected Extensions.

«Desconectar» borra el token local e intenta revocarlo en el servidor. Si no hay conexión para confirmar la revocación, la interfaz lo informa y permite revocar desde la web. Revocar o desconectar impide nuevos envíos desde esa conexión y no borra auditorías ya guardadas. Las auditorías permanecen en el espacio web, incluidas sus copias de seguridad, según la operación del servicio; para consultas sobre eliminación escribí al contacto indicado abajo. No hay una función de borrado permanente desde la interfaz.

EntiScan Web requiere una cuenta con nombre, email y contraseña; el servicio almacena el hash de la contraseña y usa cookies de sesión propias. La extensión no lee ni reutiliza esas cookies. La sesión web es independiente del token de la extensión.

Telemetría y seguimiento

La versión actual de EntiScan no utiliza telemetría, analytics ni sistemas de seguimiento de uso.

Exportación de auditorías

Los archivos de exportación generados por EntiScan se crean localmente en el dispositivo del usuario. EntiScan no envía automáticamente esos archivos ni su contenido a servicios externos.

Feedback

El usuario puede iniciar voluntariamente un correo de feedback desde la extensión. La URL de la página auditada sólo se incluye si el usuario selecciona expresamente la opción correspondiente. EntiScan no adjunta automáticamente HTML, findings, datos estructurados ni el contenido completo de la auditoría.

Permisos del navegador

EntiScan utiliza activeTab, scripting y sidePanel para acceder temporalmente a la página que decidís analizar, ejecutar el extractor local y mostrar resultados. La versión 0.2.0 agrega storage para conservar la conexión opcional y acceso únicamente a https://entiscan.navquo.com/* para autorizarla, consultar tus proyectos y enviar auditorías confirmadas. No solicita acceso global a todos los sitios.

Venta o transferencia de datos

EntiScan no vende datos ni los usa para publicidad. Al confirmar un envío, los datos estructurados se transfieren a EntiScan Web para prestar la función solicitada; no se envían a servicios de analytics, IA remota ni GSC.

Uso limitado de datos

Los datos procesados por EntiScan se utilizan exclusivamente para proporcionar las funciones de auditoría solicitadas por el usuario y no se utilizan para publicidad, perfiles comerciales, evaluación crediticia ni otros fines no relacionados con la funcionalidad principal.

Cumplimiento de Uso Limitado

El uso de la información procesada por EntiScan cumple con la Política de Datos del Usuario de Chrome Web Store, incluidos los requisitos de Uso Limitado.

Cambios en esta política

Esta política puede actualizarse si EntiScan incorpora nuevas funcionalidades, integraciones o servicios. Cualquier cambio relevante será reflejado en esta página.
