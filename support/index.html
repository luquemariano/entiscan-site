Soporte de EntiScan

Cómo usar EntiScan

  1. Abrí una página web HTTP o HTTPS.
  2. Pulsá el icono de EntiScan.
  3. Se abrirá el Side Panel.
  4. Revisá Resumen, Plan de acción, Headings, Links, Images, Datos estructurados, Social, Técnico, Entidades y Coherencia.
  5. Usá Exportar auditoría para generar Markdown, CSV o JSON localmente.

Páginas no compatibles

EntiScan no puede analizar páginas internas o protegidas del navegador, por ejemplo:

  • chrome://
  • chrome-extension://
  • Chrome Web Store
  • otras páginas que Chrome no permite inspeccionar

Privacidad

El análisis se ejecuta localmente en el navegador y no se envía automáticamente a servidores externos.

Leer la Política de Privacidad

Feedback

El usuario puede enviar feedback desde la propia extensión.

La URL auditada sólo se incluye si el usuario lo selecciona expresamente.
